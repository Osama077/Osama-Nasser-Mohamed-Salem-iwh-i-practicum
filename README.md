# Osama-Nasser-Mohamed-Salem-iwh-i-practicum

Node.js app to manage **Schools** custom object in HubSpot.

## Custom Object List View
https://app.hubspot.com/contacts/147093095/objects/2-194230553/views/all/list

## Features
- List all schools in a responsive table
- Form to create new school (Name required)
- Modern UI with gradients and shadows
- Uses Express, Pug, Axios, and .env for security
